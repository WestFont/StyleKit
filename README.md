# StyleKit

The official API for StyleKit. Instant, high-performance UI effects and components for web projects

StyleKit is a Components-as-a-Service developed by westfont for leron.io for premium UI Components and effects.

[Get API Key](https://westfont.com) • [Docs](https://westfont.com/StyleKit/Doc)

<br>

## Quick Start

**1. Install**

```html
<script src="https://stylekit.com"></script>
```

**2. Target**

```html
<div id="card">
  <h1>Hello</h1>
</div>
```

**3. Apply**

```html
<script>
  StyleKit.glassEffect('#card')
</script>
```

<br>

## Effects

| API                | What it does             |
